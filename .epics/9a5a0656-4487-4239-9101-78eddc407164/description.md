Улучшения UI рана и исправление багов:

1. **Run log UX** — текущий вывод в логах рана некрасивый, нужен user-friendly формат с возможностью разворачивать/сворачивать записи
2. **Per-project pause** — пауза должна работать per-project, а не на весь ран целиком
3. **Bug: completed epic leaks into list** — при выключенном фильтре готовых эпиков крайний готовый эпик попадает в выдачу
4. **Newest-first log order** — новые сообщения в логе рана должны показываться сверху, а не добавляться в конец
5. **Preserve run history** — сохранять историю рана пока он выполняется
